# Site Fabio Camolesi

Site institucional / portfólio de Fabio Camolesi — terapeuta holístico, acupunturista e
especialista em Medicina Tradicional Chinesa.

Construído com React + TypeScript + Vite + Tailwind CSS v4.

## Conteúdo do site

- **Hero** — apresentação e chamadas para agendamento
- **Sobre** — biografia, formação e filosofia de trabalho do Fabio
- **Método** — serviços oferecidos (acupuntura, auriculoterapia, moxabustão, ventosaterapia,
  fitoterapia chinesa, tuiná)
- **Como a acupuntura age** — mecanismos de ação (visão tradicional e científica), etapas de
  uma sessão e principais indicações
- **Trabalhos** — galeria ilustrativa de atendimentos
- **Depoimentos** — prova social com relatos de públicos diversos (crianças, gestantes,
  adolescentes, idosos, adultos)
- **FAQ** — perguntas frequentes
- **Contato** — CTA final, rodapé com dados de contato e botão flutuante do WhatsApp

> Todo o conteúdo (textos, depoimentos e imagens ilustrativas) é **fictício** e serve para
> validar o layout. Deve ser substituído por conteúdo real do Fabio conforme o projeto avança.

## Desenvolvimento

```bash
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # build de produção
npm run lint     # lint (oxlint)
```

## Dados de contato

Os dados de contato (WhatsApp, e-mail, Instagram) estão centralizados em `src/data/site.ts`.
